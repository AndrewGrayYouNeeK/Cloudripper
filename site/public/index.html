Download

Prebuilt v0.2.0 binaries for Windows, macOS, and Linux. No Go required. The files are the v0.2.0 release. The binaries are not code-signed. If you have Go 1.26.10 or newer, the go install command at the top of the page works too.

CloudRipper is a command-line tool for computers. Copy this page or share it, then open it on a computer to download and run the CLI.

Windows v0.2.0 zip archives. SHA-256 checksums for the v0.2.0 archives are in checksums.txt.

Most Windows PCs are amd64. Windows on ARM is arm64.

Windows amd64

  1. Download

    Download cloudripper_0.2.0_windows_amd64.zip

    In PowerShell, curl.exe is the curl binary:

    curl.exe -LO https://github.com/AndrewGrayYouNeeK/Cloudripper/releases/latest/download/cloudripper_0.2.0_windows_amd64.zip

  2. Extract

    Unzip the archive in PowerShell. It contains cloudripper.exe, LICENSE, README.md, and CHANGELOG.md.

    Expand-Archive -Path .\cloudripper_0.2.0_windows_amd64.zip -DestinationPath .

  3. Allow the unsigned binary

    The release binaries are not code-signed. When SmartScreen appears, choose More info, then Run anyway.

  4. Put it on your PATH

    Move cloudripper.exe into a folder that is already on your PATH. Windows runs that file when you type cloudripper.

  5. Run the demo

    cloudripper demo prints rip, cost, and optimize-style output for a fictional sample embedded in the binary. It does not read credentials and does not make network calls.

    cloudripper demo

🧹
Cloud waste scanner
Spots idle, orphaned and oversized resources across AWS, GCP and Azure. Cloudflare inventory is read-only (Workers, R2, KV, D1, and Pages) and does not invent stop or start actions. Per-resource Cloudflare cost is unpriced.

    
💵
Spend
Reads trailing spend from Cost Explorer, a BigQuery billing export, Azure Cost Management, or Cloudflare billing history when those APIs respond. Estimates are used for priced inventory when a billing API is missing or denies the call, and the two numbers are reported separately. Cloudflare billing history needs Billing Read and is not a per-resource price.

    
🔎
Find forgotten bills
The find-bills command hunts down paid services you signed up for and forgot, from your receipts and a bank CSV export. Mail access is read-only and only happens when you configure IMAP or Gmail.

    
💥
Safe chaos tests
Run controlled failure experiments inside a blast-radius limit. With no CHAOS_ENDPOINT the command prints a plan and does not post it. Names that look like production need --allow-prod.

How it works

  
Three steps. Scanning only needs read-only access.

  
    
    
  1. Install
    Download a prebuilt binary for Linux, macOS, or Windows from the download steps, or run one go install command.
    2. 
    
  2. Connect read-only
    Scans need only read-only access. optimize, schedule, and scale change AWS, GCP, or Azure resources only when you pass --apply. --dry-run still wins if both are set. A live change asks for confirmation on a terminal, or --yes when stdin is not a terminal. Cloudflare mutations are refused.
    3. 
    
  3. Scan & act
    You get inventory, spend (an actual total when a billing API responds, otherwise an estimate), and forgotten-bill matches. Chaos posts only when CHAOS_ENDPOINT is set. Slack or email alerts are sent only if you configure them.
    4. 
  

  
$ go install github.com/AndrewGrayYouNeeK/Cloudripper/cmd/cloudripper@latest
$ cloudripper rip             # inventory what is running in your cloud accounts
$ cloudripper cost            # actual vs. estimated spend
$ cloudripper find-bills      # surface forgotten paid services
$ cloudripper --help          # see cost and chaos-test commands

  
Read-only scans. rip and cost do not change resources. optimize, schedule, and scale require --apply before they change anything, and --dry-run still wins if both are set. Cloudflare is read-only. Chaos does not use --apply; it posts only when CHAOS_ENDPOINT is set. The CLI calls each cloud's own APIs with credentials that stay on your machine. Your cloud data is never sent to us.

FAQ

  

  
Is CloudRipper really free?
Yes. The CLI is open source under the MIT license and free to use, including commercially. Paid plans are only for the optional hosted dashboard.

  
Is it safe to point at my cloud account?
Scans need only read-only access. optimize, schedule, and scale change AWS, GCP, or Azure only when you pass --apply, and --dry-run still wins if both are set. A live change asks for confirmation on a terminal, or --yes when stdin is not a terminal. Cloudflare mutations are refused. Chaos posts only when CHAOS_ENDPOINT is set, and production-looking names need --allow-prod.

  
Where do my credentials go?
The CLI runs on your machine and uses your local credentials to call AWS, GCP, Azure, or Cloudflare directly. Your cloud data is never sent to us. The waitlist form on this site stores the email you submit. Slack and email alerts run only if you configure them. find-bills talks to IMAP or Gmail only when you point it there.

  
Which clouds are supported?
AWS, Google Cloud (GCP), Microsoft Azure, and Cloudflare. Cloudflare inventory is read-only. Billing history needs Billing Read. Per-resource Cloudflare costs are unpriced.

  
What does find-bills do?
It looks through mail you configure (IMAP or Gmail, read-only) and an optional bank or card CSV for recurring paid services you may have forgotten about.
